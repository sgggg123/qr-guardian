## 1. 서비스 소개

**QR Guardian**는 QR 코드나 URL의 보안 위험을 사전에 분석해주는 서비스입니다.

실제 사이트에 접속하지 않아도, 해당 링크가 피싱·사기·악성 사이트인지 미리 확인할 수 있습니다.

**주요 기능**
- QR 코드 및 URL 보안 검사
- 위험도 신호등 방식 표시 (안전 / 주의 / 위험)
- AI 기반 보안 요약 제공
- 스캔 기록 저장 및 조회
- 의심 URL 신고
- QR 코드 직접 생성

## 2. URL 검사 방법

홈 화면에서 아래 세 가지 방법 중 하나를 선택하여 검사를 시작할 수 있습니다.

---

### 2-1. 카메라로 QR 코드 스캔

실물 QR 코드(포스터, 결제 화면, 홍보물 등)를 바로 인식할 때 사용합니다.

1. 홈 화면에서 카메라 스캐너 영역을 확인합니다.
2. QR 코드를 카메라에 가져다 댑니다.
3. 인식되면 자동으로 분석이 시작됩니다.

> 카메라 권한 허용이 필요합니다.

---

### 2-2. QR 이미지 붙여넣기

메신저, SNS, 캡처 이미지 등 저장된 QR 코드를 분석할 때 사용합니다.

1. QR 코드 이미지를 클립보드에 복사합니다. (캡처 후 복사 또는 이미지 우클릭 → 복사)
2. 홈 화면에서 **Ctrl+V** 를 누릅니다.
3. 이미지에서 QR 코드를 자동으로 인식하여 분석을 시작합니다.

---

### 2-3. URL 직접 입력

QR 코드 없이 일반 링크를 직접 검사할 때 사용합니다.

1. 홈 화면 하단 URL 입력창에 검사할 주소를 입력합니다.
2. **URL 검사** 버튼을 클릭하거나 **Enter** 키를 누릅니다.

---

### 분석 진행 화면

검사 중에는 아래 7단계가 순서대로 진행됩니다.

| 단계 | 내용 |
|------|------|
| 1 | URL 읽는 중 |
| 2 | URL 구조 분석 |
| 3 | 리다이렉트 경로 추적 |
| 4 | 위협 데이터베이스 조회 |
| 5 | 도메인 보안 검사 |
| 6 | SSL 인증서 검증 |
| 7 | AI 위험도 분석 |

모든 단계가 완료되면 자동으로 결과 화면으로 이동합니다.

## 3. 분석 결과 확인

분석이 완료되면 아래 정보를 한 화면에서 확인할 수 있습니다.

---

### 3-1. 위험도 신호등

화면 상단에 **초록 / 노랑 / 빨강** 색상으로 위험 수준을 직관적으로 표시합니다.
자세한 기준은 [4. 위험도 등급 안내](#4-위험도-등급-안내)를 참고하세요.

---

### 3-2. 보안 검사 항목

다음 6가지 항목을 종합 분석한 결과를 제공합니다.

| 검사 항목 | 내용 |
|-----------|------|
| SSL 인증서 | HTTPS 여부 및 인증서 유효성 확인 |
| 도메인 신뢰도 | 도메인 나이, 등록 정보 분석 |
| 리다이렉트 추적 | 링크 클릭 시 실제로 이동하는 최종 목적지 확인 |
| 타이포스쿼팅 감지 | 네이버, 구글 등 유명 사이트를 사칭하는 유사 도메인 탐지 |
| 피싱 패턴 분석 | 피싱 의심 키워드 및 패턴 탐지 |
| 개인정보 수집 탐지 | 로그인·비밀번호 등 개인정보 수집 경로 감지 |

---

### 3-3. 사이트 미리보기

실제 사이트에 접속하지 않고도 화면을 미리 볼 수 있습니다.

- 결과 화면에서 **미리보기** 버튼을 클릭하면 외부 스크린샷으로 사이트 외관을 확인할 수 있습니다.
- 위험 판단 전 사이트 내용을 안전하게 사전 확인할 때 유용합니다.

---

### 3-4. 액션 버튼

| 버튼 | 동작 |
|------|------|
| **URL 열기** | 안전 판정 시 해당 사이트로 이동 |
| **위험을 감수하고 열기** | 주의·위험 판정 시 경고 확인 후 이동 |
| **복사** | 최종 URL을 클립보드에 복사 |
| **공유** | 링크 공유 |
| **신고** | 위험 URL로 신고 접수 |

## 4. 위험도 등급 안내

위험도는 0~10점으로 산출되며, 3단계 등급으로 표시됩니다.

| 등급 | 점수 | 의미 |
|------|------|------|
| 🟢 **안전 (GREEN)** | 0.0 ~ 2.9점 | 위협 요소가 발견되지 않은 안전한 링크 |
| 🟡 **주의 (YELLOW)** | 3.0 ~ 6.9점 | 경미한 위험 요소가 있으나 즉각적인 위협은 낮음 |
| 🔴 **위험 (RED)** | 7.0 ~ 10.0점 | 피싱, 사칭 등 심각한 위협이 감지된 링크 |

> **주의·위험 등급의 링크는 접속을 자제하고, 출처를 반드시 확인하세요.**

## 5. AI 보안 요약

분석 결과를 바탕으로 AI가 해당 링크의 위험 원인과 행동 수칙을 이해하기 쉬운 말로 요약해드립니다.

- 왜 위험(또는 안전)으로 판단되었는지 핵심 내용을 설명합니다.
- 사용자가 취해야 할 행동 수칙을 번호 순서로 안내합니다.
- AI 요약이 적용된 경우 **AI** 뱃지가 함께 표시됩니다.

## 6. 스캔 기록 관리

검사한 모든 URL은 기기에 자동으로 저장됩니다.

### 기록 확인 방법

하단 내비게이션에서 **기록** 탭을 선택하면 이전 검사 결과 목록을 확인할 수 있습니다.

### 기록 화면 구성

- **통계 요약**: 전체·오늘·이번 주 스캔 횟수와 위험도 분포를 한눈에 확인
- **기록 목록**: 각 항목에 위험도 등급, URL, 검사 시간이 표시됨
- **항목 클릭**: 이전 분석 결과를 다시 열람 가능

### 기록 삭제

- 개별 삭제: 항목 우측 **X** 버튼
- 전체 삭제: 화면 우상단 **전체 삭제** 버튼

## 7. 위험 URL 신고

위험하다고 판단된 링크를 신고하여 다른 사용자의 피해를 예방할 수 있습니다.

1. 분석 결과 화면 하단에서 **신고** 버튼을 클릭합니다.
2. 신고가 접수되면 누적 신고 건수가 표시됩니다.
3. 동일한 URL은 1회만 신고 가능합니다.

---

## 8. QR 코드 생성

안전한 QR 코드를 직접 만들 수 있습니다.

1. 하단 내비게이션에서 **생성** 탭을 선택합니다.
2. QR 코드로 변환할 URL을 입력합니다.
3. **QR 코드 생성** 버튼을 클릭합니다.
4. 생성된 QR 코드를 **다운로드(PNG)** 하거나 **클립보드에 복사**할 수 있습니다.

---

## 9. 설정

하단 내비게이션에서 **설정** 탭을 선택하여 앱 환경을 변경할 수 있습니다.

| 설정 항목 | 내용 |
|-----------|------|
| **다크 모드 / 라이트 모드** | 화면 테마 전환 |
| **효과음** | 검사 결과에 따른 알림음 활성화·비활성화 |
| **진동** | 위험 감지 시 진동 알림 활성화·비활성화 |
| **알림 테스트** | 안전·주의·위험 각 등급의 알림을 미리 체험 |

## 자주 묻는 질문

**Q. 카메라가 QR 코드를 인식하지 못해요.**
→ 카메라 권한이 허용되어 있는지 확인하세요. 브라우저 주소창 옆 자물쇠 아이콘 → 카메라 권한 허용.

**Q. 안전 판정이 나왔는데도 조심해야 하나요?**
→ 모든 위협을 100% 탐지하지는 않습니다. 출처가 불분명한 링크는 안전 판정이어도 주의하는 것이 좋습니다.

**Q. 스캔 기록은 어디에 저장되나요?**
→ 기록은 사용자의 기기(브라우저)에만 저장되며, 외부 서버에 업로드되지 않습니다.

**Q. 신고하면 어떻게 되나요?**
→ 신고된 URL은 시스템에 위험 URL로 접수됩니다. 다른 사용자가 동일 URL 검사 시 참고 데이터로 활용됩니다.
