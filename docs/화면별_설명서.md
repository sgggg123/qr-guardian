## 1. 홈 화면 — QR 코드 스캔

**파일:** `frontend/src/pages/Home.tsx`
**경로:** `/` (앱 진입점)

### 화면 개요

앱의 메인 화면으로, QR 코드를 스캔하거나 URL을 직접 입력하여 보안 분석을 시작하는 화면입니다.

### 주요 UI 구성

| 영역 | 설명 |
|------|------|
| 제목 영역 | "QR 코드 스캔" 타이틀 및 안내 문구 |
| QR 스캐너 | 카메라 기반 QR 코드 스캐너 컴포넌트 |
| 구분선 | "또는 직접 입력 / Ctrl+V로 QR 이미지 붙여넣기" |
| URL 입력창 | 수동 URL 직접 입력 텍스트 필드 |
| URL 검사 버튼 | 분석 시작 버튼 |
| 로딩 오버레이 | 분석 진행 중 전체 화면 오버레이 |
| 오류 메시지 | 분석 실패 시 빨간 경고 박스 |

### 입력 방식 (3가지)

1. **카메라 스캔**
   - `QRScanner` 컴포넌트를 통해 실시간 카메라 QR 스캔
   - 스캔 성공 즉시 분석 파이프라인 시작

2. **수동 URL 입력**
   - 텍스트 필드에 URL 직접 타이핑
   - "URL 검사" 버튼 클릭 또는 Enter 키로 제출

3. **Ctrl+V 이미지 붙여넣기**
   - 클립보드에 복사된 QR 코드 이미지를 Ctrl+V로 붙여넣기
   - `jsQR` 라이브러리로 이미지에서 QR 코드를 자동 인식
   - 인식 중에는 "QR 코드 이미지 분석 중..." 안내 메시지 표시

### 분석 진행 오버레이 (로딩 화면)

분석 중에는 전체 화면을 덮는 오버레이가 표시되며, 7단계 진행 상황을 실시간으로 보여줍니다.

| 단계 | 메시지 | 진행률 |
|------|--------|--------|
| 1 | QR 코드에서 URL 읽는 중... | 8% |
| 2 | URL 구조 분석 중... | 20% |
| 3 | 리다이렉트 경로 추적 중... | 35% |
| 4 | 위협 데이터베이스 조회 중... | 52% |
| 5 | 도메인 보안 검사 중... | 66% |
| 6 | SSL 인증서 검증 중... | 79% |
| 7 | AI 위험도 분석 중... | 91% |
| 완료 | ✓ 분석 완료! | 100% |

- 오버레이 하단에는 결과 화면 미리보기 스켈레톤이 표시됩니다.
- 완료 시 초록색 체크 아이콘으로 변경됩니다.

### 분석 완료 후 동작

1. 분석 결과를 `IndexedDB` 스캔 기록에 자동 저장
2. 위험도에 따른 알림음/진동 실행 (설정에 따라)
3. `/result` 화면으로 자동 이동

### 오류 처리

- API 실패, 네트워크 오류 등 발생 시 빨간 박스에 오류 메시지 표시
- "닫기" 버튼으로 오류 메시지 수동 닫기 가능

## 2. 분석 결과 화면

**파일:** `frontend/src/pages/Result.tsx`
**경로:** `/result`

### 화면 개요

URL 보안 분석의 최종 결과를 표시하는 화면입니다. 위험도 신호등, AI 요약, 상세 분석 정보, 행동 수칙을 제공합니다.

### 주요 UI 구성

| 영역 | 설명 |
|------|------|
| 신호등 인디케이터 | 위험도를 초록/노랑/빨강으로 시각화 (Large 크기) |
| 분석 요약 카드 | AI 요약 또는 템플릿 요약 (AI 우선) |
| URL 정보 | 원본 URL과 최종 목적지 URL |
| 행동 수칙 | AI가 생성한 번호별 권고 행동 목록 |
| 위협 플래그 목록 | 감지된 위협 항목 배지 목록 |
| 정보 수집 경고 | 개인정보 수집 위험 경고 |
| Safe Browsing 결과 | Google Safe Browsing API 결과 |
| 도메인 분석 카드 | 도메인 연령, SSL 등급, WHOIS 정보 |
| 리다이렉트 체인 | 리다이렉트 경로 시각화 (2홉 이상 시 표시) |
| 사이트 미리보기 | 실제 접속 없이 스크린샷으로 사이트 외관 확인 |
| 액션 버튼 영역 | URL 열기, 복사, 공유, 신고 버튼 |
| 다시 스캔 버튼 | 홈 화면으로 이동 |

### 분석 요약 카드 — 위험도별 스타일

| 위험도 | 배경 | 아이콘 | 텍스트 색상 |
|--------|------|--------|-------------|
| GREEN (안전) | 초록 배경 | 체크 원형 | 초록 |
| YELLOW (주의) | 노랑 배경 | 경고 삼각형 | 노랑 |
| RED (위험) | 빨강 배경 | 느낌표 원형 | 빨강 |

- AI 요약이 있을 경우 "AI" 뱃지가 함께 표시됩니다.

### 사이트 미리보기

- 기본 상태: 숨김 (직접 접속 없이 확인 가능하다는 안내 문구만 표시)
- "미리보기" 버튼 클릭 시 외부 스크린샷 서비스를 통해 사이트 이미지 로드
- 로딩 중: 스피너 + "스크린샷 로딩 중..." 표시
- 15초 타임아웃 후 실패 시: "다시 시도" 버튼과 함께 실패 안내 표시

### 액션 버튼 상세

| 버튼 | 조건 | 동작 |
|------|------|------|
| **URL 열기** (초록) | GREEN 판정 시 | 확인 다이얼로그 후 새 탭으로 URL 열기 |
| **위험을 감수하고 열기** (회색) | YELLOW/RED 판정 시 | 경고 확인 다이얼로그 후 새 탭으로 URL 열기 |
| **복사** | 항상 | 최종 URL을 클립보드에 복사 |
| **공유** | 항상 | 네이티브 공유 API 사용, 불가 시 텍스트 클립보드 복사 |
| **신고** | 항상 (1회 한정) | 백엔드에 위험 URL 신고 접수, 접수 후 비활성화 + 누적 신고 건수 표시 |

### 토스트 알림

- 복사/공유/신고 성공 시: 상단 중앙에 초록 토스트 2초 표시
- 신고 실패 시: 상단 중앙에 빨간 토스트 3초 표시

## 3. 스캔 기록 화면

**파일:** `frontend/src/pages/History.tsx`
**경로:** `/history`

### 화면 개요

이전에 스캔한 모든 URL의 이력을 보여주는 화면입니다. 통계 요약과 함께 각 항목을 클릭하면 상세 결과를 재열람할 수 있습니다.

### 주요 UI 구성

| 영역 | 설명 |
|------|------|
| 제목 + 전체 삭제 버튼 | "스캔 기록" 제목, 기록이 있을 때 우상단에 "전체 삭제" 버튼 표시 |
| 통계 카드 | 전체/오늘/이번 주 스캔 횟수 + 위험도 분포 바 차트 |
| 기록 목록 | 스캔 항목 리스트 |
| 새 스캔 버튼 | 홈 화면으로 이동 |

### 통계 카드 상세

- **전체**: 누적 스캔 총 횟수
- **오늘**: 오늘 스캔 횟수
- **이번 주**: 이번 주 스캔 횟수
- **위험도 분포 바**: 안전(초록)/주의(노랑)/위험(빨강) 비율을 가로 바로 시각화

### 기록 목록 항목 구성

각 항목은 다음 정보를 표시합니다:

| 요소 | 설명 |
|------|------|
| 위험도 뱃지 | 안전(초록)/주의(노랑)/위험(빨강) 색상 뱃지 |
| 신뢰도 점수 | "신뢰도 X점" 텍스트 |
| URL | 모노스페이스 폰트로 표시 (긴 URL은 말줄임표) |
| 시간 | 상대적 시간 표시 (방금 전 / N분 전 / N시간 전 / N일 전 / 날짜) |
| 삭제 버튼 | 개별 항목 삭제 (X 아이콘) |

### 시간 표시 형식

| 경과 시간 | 표시 형식 |
|-----------|-----------|
| 1분 미만 | 방금 전 |
| 1~59분 | N분 전 |
| 1~23시간 | N시간 전 |
| 1~6일 | N일 전 |
| 7일 이상 | YYYY. MM. DD. (한국어 날짜) |

### 상호작용

- **항목 클릭**: 해당 스캔의 상세 결과 화면(`/result`)으로 이동
- **삭제(X) 클릭**: 해당 항목만 즉시 삭제 (목록과 통계 실시간 갱신)
- **전체 삭제**: 확인 다이얼로그 후 모든 기록 삭제

### 빈 상태

기록이 없을 때는 시계 아이콘과 함께 "스캔 기록이 없습니다" 메시지, "첫 스캔 시작하기" 링크를 표시합니다.

## 4. QR 코드 생성 화면

**파일:** `frontend/src/pages/Generate.tsx`
**경로:** `/generate`

### 화면 개요

입력한 URL을 QR 코드 이미지로 변환하여 다운로드하거나 클립보드에 복사할 수 있는 화면입니다.

### 주요 UI 구성

| 영역 | 설명 |
|------|------|
| 제목 영역 | "QR 코드 생성" 타이틀 및 안내 문구 |
| URL 입력창 | QR 코드로 변환할 URL 입력 |
| QR 코드 생성 버튼 | URL 입력 시 활성화 |
| QR 코드 표시 영역 | 생성된 QR 코드 SVG 이미지 (흰 배경) |
| 인코딩된 URL 표시 | 입력 URL을 모노스페이스로 표시 |
| 다운로드 버튼 | PNG 파일로 저장 |
| 복사 버튼 | 클립보드에 이미지 복사 |
| 스캔으로 돌아가기 | 홈 화면 이동 링크 |

### QR 코드 생성 사양

- 라이브러리: `qrcode.react` (SVG 방식)
- 크기: 200 × 200 px (표시), 512 × 512 px (저장)
- 오류 정정 수준: H (최고 수준, 최대 30% 손상까지 복구 가능)
- 여백: 포함 (includeMargin: true)

### 다운로드 동작

1. SVG를 `XMLSerializer`로 문자열 변환
2. Canvas(512×512)에 흰 배경 + QR 코드 그리기
3. `canvas.toDataURL('image/png')` 로 PNG 데이터 URL 생성
4. `qr-code.png` 파일명으로 자동 다운로드

### 복사 동작

- `navigator.clipboard.write()`로 PNG Blob을 클립보드에 이미지로 복사
- 성공 시 "QR 코드가 클립보드에 복사되었습니다" 알림
- 실패 시 "복사에 실패했습니다" 알림

### URL 변경 시 동작

- URL 입력값이 변경되면 `generated` 상태가 초기화되어 기존 QR 코드가 숨겨집니다.

## 5. 설정 화면

**파일:** `frontend/src/pages/Settings.tsx`
**경로:** `/settings`

### 화면 개요

앱의 외관 테마, 알림 방식 등 사용자 환경 설정을 변경하는 화면입니다.

### 설정 섹션

#### 테마 설정

| 항목 | 설명 |
|------|------|
| 다크 모드 / 라이트 모드 토글 | 현재 테마에 따라 달 아이콘(다크) 또는 태양 아이콘(라이트) 표시 |
| 현재 테마 안내 | "현재 어두운/밝은 테마 사용 중" 텍스트 |
| 토글 스위치 | 클릭 즉시 테마 전환, `ThemeContext`를 통해 전체 앱에 적용 |

#### 알림 설정

**효과음 토글**
- 위험도에 따른 알림음 활성화/비활성화
- 활성화 시 GREEN 레벨 테스트 음향 재생

**진동 토글**
- 위험 감지 시 진동 알림 활성화/비활성화
- 활성화 시 GREEN 레벨 테스트 진동 실행

**알림 테스트 버튼**

| 버튼 | 색상 | 동작 |
|------|------|------|
| 안전 | 초록 | GREEN 레벨 효과음 + 진동 테스트 |
| 주의 | 노랑 | YELLOW 레벨 효과음 + 진동 테스트 |
| 위험 | 빨강 | RED 레벨 효과음 + 진동 테스트 |

#### 앱 정보

| 항목 | 값 |
|------|-----|
| 버전 | 1.0.0 |
| 개발 | QR Guardian Team |

### 설정 저장 방식

- 알림 설정은 `localStorage`에 JSON으로 저장
- 테마 설정은 `ThemeContext`를 통해 관리

## 7. 사용 가이드 화면

**파일:** `frontend/src/pages/Help.tsx`
**경로:** `/help`

### 화면 개요

QR Guardian의 작동 원리, 탐지 항목, 신호등 판정 기준을 설명하고, 실제 URL로 탐지를 체험해볼 수 있는 안내 화면입니다.

### 섹션 구성

#### 1) 작동 원리

4단계 순서로 분석 과정을 설명합니다:

1. QR 코드 스캔 또는 URL 직접 입력
2. 리다이렉트 추적으로 최종 목적지 URL 확인
3. 도메인 신뢰도, SSL, 타이포스쿼팅, 피싱 패턴 종합 분석
4. 신호등 방식(초록/노랑/빨강)으로 위험도 표시

#### 2) 탐지 항목 (6가지)

| 탐지 항목 | 설명 |
|-----------|------|
| SSL 인증서 검증 | HTTPS 여부 및 인증서 유효성/신뢰도 확인 |
| 도메인 신뢰도 | 도메인 연령, WHOIS 정보, 등록 기관 분석 |
| 리다이렉트 추적 | 최대 10홉 리다이렉트 체인 추적 |
| 타이포스쿼팅 감지 | 유사 도메인명 브랜드 사칭 탐지 (Levenshtein 거리) |
| 피싱 패턴 분석 | 정규식 기반 피싱 키워드/패턴 분석 |
| 개인정보 수집 탐지 | login, password, account 등 수집 경로 감지 |

#### 3) 신호등 판정 기준

| 신호 | 위험도 점수 | 의미 |
|------|------------|------|
| 초록 (안전) | 0.0 ~ 2.9점 | 위협 요소가 발견되지 않은 안전한 URL |
| 노랑 (주의) | 3.0 ~ 6.9점 | 경미한 위험 요소가 있으나 큰 문제는 없음 |
| 빨강 (위험) | 7.0 ~ 10.0점 | 피싱, 타이포스쿼팅 등 심각한 위협 감지 |

#### 4) 탐지 체험 (Demo)

실제 URL을 스캔하여 결과를 직접 확인해볼 수 있습니다:

| URL | 예상 판정 | 설명 |
|-----|-----------|------|

## 부록 — 위험도 점수 체계

| 평가 항목 | 최대 점수 | 조건 |
|-----------|----------|------|
| 도메인 연령 | 4.0점 | 30일 미만 = 4점, 90일 미만 = 2점, 1년 미만 = 1점 |
| SSL 상태 | 3.0점 | HTTP = 3점, 만료/저신뢰 = 2점, 만료 임박 = 1점, 유효 = 0점 |
| Safe Browsing | 2.0점 | 위협 감지 = 2점, 안전 = 0점 |
